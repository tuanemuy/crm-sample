# 顧客基本情報編集のテストケース

## 基本機能テスト

### 編集画面表示テスト
**説明**: 編集画面が正しく表示され、現在の顧客情報が入力済みであることを確認する

### 情報更新テスト
**説明**: 変更した情報が正しく保存されることを確認する

### 更新成功メッセージテスト
**説明**: 更新後に成功メッセージが表示されることを確認する

### 編集キャンセルテスト
**説明**: キャンセルボタンで変更を破棄できることを確認する

## 会社情報編集テスト

### 会社名変更テスト
**説明**: 会社名を変更できることを確認する

### 会社名重複チェックテスト
**説明**: 既存の会社名と重複する場合に警告が表示されることを確認する

### 業界変更テスト
**説明**: 業界をドロップダウンから選択して変更できることを確認する

### 企業規模変更テスト
**説明**: 企業規模（従業員数、資本金）を変更できることを確認する

### 設立年月日変更テスト
**説明**: 設立年月日を日付ピッカーで変更できることを確認する
