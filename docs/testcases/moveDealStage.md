# ステージ間の商談移動 テストケース

## 概要
商談をステージ間でドラッグ＆ドロップで移動する機能のテストケース

## 基本機能テスト

### TC001: 隣接ステージへの移動 - 正常パターン
**テストケース名**: 商談を隣接するステージに移動する
**説明**: ドラッグ&ドロップで商談を次のステージに移動
**前提条件**: 
- ユーザーがログインしている
- 商談移動権限を持っている
- パイプライン画面が表示されている
- 移動可能な商談が存在する
**テストステップ**:
1. パイプライン画面を開く
2. 商談カードをドラッグ
3. 隣接ステージにドロップ
4. 移動確認ダイアログで確定
**期待結果**: 
- 商談が新しいステージに移動する
- パイプライン画面が自動更新される
- 移動履歴が記録される

### TC002: 複数ステージスキップの移動 - 正常パターン
**テストケース名**: 商談を複数ステージ先に移動する
**説明**: 中間ステージを飛ばして移動
**前提条件**: 
- 複数ステージスキップが許可されている
**テストステップ**:
1. 商談を2ステージ先のエリアにドラッグ&ドロップ
2. スキップ理由を入力
3. 移動を確定
**期待結果**: 
- 商談が指定ステージに移動する
- スキップ理由が履歴に記録される
- 中間ステージの処理が自動完了される

### TC003: 後方ステージへの移動 - 正常パターン
**テストケース名**: 商談を前のステージに戻す
**説明**: より早い段階のステージに商談を戻す
**前提条件**: 
- 後退移動が許可されている
**テストステップ**:
1. 商談を前のステージにドラッグ&ドロップ
2. 後退理由を選択
3. 移動を実行
**期待結果**: 
- 商談が前のステージに移動する
- 後退理由が記録される
- 関連データのステータスが更新される

### TC004: 複数商談の同時移動 - 正常パターン
**テストケース名**: 複数の商談を同時に移動する
**説明**: 複数選択した商談を一括でステージ移動
**前提条件**: 
- 複数選択機能が利用可能
**テストステップ**:
1. Ctrlキーを押しながら複数の商談を選択
2. 選択したカードをドラッグ
3. 移動先ステージにドロップ
**期待結果**: 
- 選択したすべての商談が移動する
- 一括移動のログが記録される
- 処理件数が表示される

## 異常系テスト

### TC005: 権限不足での移動 - エラーパターン
**テストケース名**: 移動権限のない商談を移動しようとする
**説明**: アクセス権限チェックの動作確認
**前提条件**: 
- 移動権限のない商談が存在
**テストステップ**:
1. 権限のない商談をドラッグ
2. 他のステージにドロップを試みる
**期待結果**: 
- ドラッグが無効になる
- 権限エラーメッセージが表示される
- 移動は実行されない

### TC006: 無効なステージへの移動 - エラーパターン
**テストケース名**: 移動が許可されていないステージに移動
**説明**: ビジネスルールによる移動制限
**前提条件**: 
- ステージ移動ルールが設定されている
**テストステップ**:
1. 商談を無効なステージにドロップ
**期待結果**: 
- 移動が拒否される
- 制限理由が表示される
- 商談は元のステージに戻る

### TC007: 同一ステージ内での移動 - 正常パターン
**テストケース名**: 同じステージ内で商談を移動する
**説明**: ステージ内での並び順変更
**前提条件**: 
- ステージ内に複数の商談が存在
**テストステップ**:
1. 商談を同じステージ内の別の位置にドロップ
**期待結果**: 
- 表示順序が変更される
- ステージは変わらない
- 並び順が保存される

## バリデーション機能テスト

### TC008: 必須フィールドチェック - バリデーションテスト
**テストケース名**: 移動先ステージの必須項目が未入力の場合

**期待結果**:

**説明**: 金額が設定されていない場合の制御
**前提条件**: 
- 金額確認が必要なステージが存在
**テストステップ**:
1. 金額未設定の商談を該当ステージに移動
**期待結果**: 
- 金額入力ダイアログが表示される
- 金額設定なしでは移動不可
- 適切な金額設定で移動完了

- データの整合性が保たれる

2. ユーザーBが商談を移動

**期待結果**: 
- 自動的に画面が更新される
- 移動した商談が新しい位置に表示
- 更新通知が表示される
