# ダッシュボードカスタマイズ テストケース

## 概要
ダッシュボードのウィジェット配置や表示内容をカスタマイズする機能のテストケース

## 基本機能テスト

### TC001: ウィジェットの追加 - 正常パターン
**テストケース名**: ダッシュボードに新しいウィジェットを追加する
**説明**: 利用可能なウィジェットからダッシュボードに配置
**前提条件**: 
- ユーザーがログインしている
- ダッシュボードカスタマイズ権限を持っている
- 利用可能なウィジェットが存在する
**テストステップ**:
1. ダッシュボード画面を開く
2. 「カスタマイズ」ボタンをクリック
3. ウィジェットライブラリから「売上グラフ」を選択
4. ダッシュボードの空いた場所にドラッグ&ドロップ
5. 設定を保存
**期待結果**: 
- ウィジェットが正常に追加される
- 追加したウィジェットが機能する
- レイアウトが適切に調整される

### TC002: ウィジェットの移動 - 正常パターン
**テストケース名**: 既存ウィジェットの位置を変更する
**説明**: ドラッグ&ドロップでウィジェット配置を調整
**前提条件**: 
- カスタマイズ可能なウィジェットが配置されている
**テストステップ**:
1. カスタマイズモードに入る
2. 「今日の活動」ウィジェットを選択
3. 左上から右下の位置にドラッグ移動
4. 配置を確定
**期待結果**: 
- ウィジェットが新しい位置に移動する
- 他のウィジェットが自動で再配置される
- 移動後も正常に機能する

### TC003: ウィジェットサイズの調整 - 正常パターン
**テストケース名**: ウィジェットのサイズを変更する
**説明**: ウィジェットの幅・高さを調整してレイアウト最適化
**前提条件**: 
- サイズ変更可能なウィジェットが存在
**テストステップ**:
1. ウィジェットの端をマウスでドラッグ
2. サイズを拡大・縮小
3. 他のウィジェットとの配置を調整
4. 変更を保存
**期待結果**: 
- ウィジェットのサイズが変更される
- 内容が新しいサイズに適応される
- レイアウトの整合性が保たれる

### TC004: ウィジェットの削除 - 正常パターン
**テストケース名**: 不要なウィジェットを削除する
**説明**: ダッシュボードからウィジェットを除去
**前提条件**: 
- 削除可能なウィジェットが配置されている
**テストステップ**:
1. カスタマイズモードに入る
2. 削除したいウィジェットを選択
3. 削除ボタンまたは「×」をクリック
4. 削除確認ダイアログで確定
**期待結果**: 
- ウィジェットがダッシュボードから削除される
- 他のウィジェットが自動で再配置される
- 削除の取り消しが可能（直後のみ）

## ウィジェット設定テスト

### TC005: ウィジェット個別設定 - 設定テスト
**テストケース名**: 各ウィジェットの表示設定を変更
**説明**: タイトル、データ範囲、表示形式等の個別設定
**前提条件**: 
- 設定可能なウィジェットが配置されている
**テストステップ**:
1. ウィジェットの設定アイコンをクリック
2. タイトルを「今月の売上実績」に変更
3. 表示期間を「過去30日」に設定
4. グラフタイプを「棒グラフ」に変更
5. 設定を適用
**期待結果**: 
- ウィジェットの設定が変更される
- 新しい設定でデータが表示される
- 設定変更が即座に反映される

### TC006: データフィルターの設定 - 設定テスト
**テストケース名**: ウィジェットに表示するデータを絞り込み
**説明**: 担当者、地域、製品等でのデータフィルタリング
**前提条件**: 
- フィルター機能を持つウィジェットが存在
**テストステップ**:
1. ウィジェット設定を開く
2. フィルター条件で「担当者：自分のみ」を設定
3. 地域フィルターで「東京」を選択
4. 設定を保存
**期待結果**: 
- フィルター条件が適用される
- 絞り込まれたデータのみ表示される
- フィルター条件が明示される

## レイアウト管理テスト

### TC007: レイアウトテンプレートの適用 - テンプレートテスト
**テストケース名**: 事前定義されたレイアウトを適用
**説明**: 営業向け、管理者向け等のテンプレートレイアウト
**前提条件**: 
- レイアウトテンプレートが用意されている
**テストステップ**:
1. 「テンプレート適用」を選択
2. 「営業マネージャー向け」テンプレートを選択
3. プレビューで確認
4. 適用を実行
**期待結果**: 
- テンプレートレイアウトが適用される
- 適切なウィジェットセットが配置される
- 既存のカスタマイズが上書きされる

### TC008: レイアウトの保存・復元 - 保存テスト
**テストケース名**: カスタマイズしたレイアウトを保存
**説明**: 複数のレイアウト設定の管理
**前提条件**: 
- レイアウト保存機能が実装されている
**テストステップ**:
1. ダッシュボードをカスタマイズ
2. 「レイアウトを保存」を選択
3. 名前「営業日次レビュー」で保存
4. 異なるレイアウトに変更
5. 保存したレイアウトを復元
**期待結果**: 
- レイアウトが名前付きで保存される
- 保存したレイアウトを呼び出せる
- 複数のレイアウトを管理できる

## 権限・共有機能テスト

### TC009: チーム向けレイアウト共有 - 共有テスト
**テストケース名**: カスタマイズしたダッシュボードを共有
**説明**: 他のユーザーとレイアウト設定を共有
**前提条件**: 
- レイアウト共有機能が利用可能
- 共有対象のユーザーが存在
**テストステップ**:
1. レイアウトを完成させる
2. 「レイアウトを共有」を選択
3. 共有対象メンバーを選択
4. アクセス権限を設定
5. 共有を実行
**期待結果**: 
- 選択したメンバーがレイアウトにアクセス可能
- 権限に応じた編集制限が適用される
- 共有履歴が記録される

### TC010: 管理者による制限設定 - 権限テスト
**テストケース名**: 利用可能なウィジェットを制限
**説明**: 部門や役職に応じたウィジェット制限
**前提条件**: 
- 管理者権限を持っている
- ウィジェット制限機能が実装されている
**テストステップ**:
1. 管理者設定画面を開く
2. 一般ユーザーの利用可能ウィジェットを制限
3. 機密情報ウィジェットを管理者限定に設定
4. 設定を適用
**期待結果**: 
- 制限されたウィジェットが非表示になる
- 権限のないユーザーは制限ウィジェットを追加不可
- 制限設定が適切に機能する

## パフォーマンステスト

### TC011: 多数ウィジェットでの性能 - パフォーマンステスト
**テストケース名**: 20個以上のウィジェットを配置
**説明**: 大量ウィジェット配置時の性能確認
**前提条件**: 
- 20個以上のウィジェットが利用可能
**テストステップ**:
1. 利用可能な全ウィジェットを配置
2. ダッシュボードの表示速度を測定
3. 各ウィジェットの動作確認
**期待結果**: 
- 5秒以内にダッシュボードが表示される
- 個別ウィジェットが正常に機能する
- ブラウザがフリーズしない

## 異常系・エラーテスト

### TC012: 設定保存の失敗 - エラーパターン
**テストケース名**: ネットワーク障害時のカスタマイズ保存
**説明**: 設定保存失敗時の適切な処理確認
**前提条件**: 
- ネットワーク接続を意図的に切断可能
**テストステップ**:
1. オフライン状態でレイアウトを変更
2. 保存を試みる
3. エラー処理を確認
**期待結果**: 
- エラーメッセージが表示される
- 変更内容が一時保存される
- 接続回復時に保存の再試行が可能

### TC013: 互換性のないウィジェット - エラーパターン
**テストケース名**: 古いバージョンのウィジェットを使用
**説明**: 非対応ウィジェットの適切な処理確認
**前提条件**: 
- システムアップデート後の状況
**テストステップ**:
1. 古いバージョンのウィジェットが含まれるレイアウトを読み込み
**期待結果**: 
- 非対応ウィジェットが適切に処理される
- エラーメッセージが表示される
- 代替ウィジェットが提案される
