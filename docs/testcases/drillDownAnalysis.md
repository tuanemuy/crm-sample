# ドリルダウン分析のテストケース

## 基本機能テスト

### ドリルダウン開始テスト
**説明**: データポイントをクリックしてドリルダウン分析を開始できることを確認する

### 階層レベル表示テスト
**説明**: 現在のドリルダウン階層レベルが表示されることを確認する

### 詳細データ表示テスト
**説明**: ドリルダウン先の詳細データが表示されることを確認する

### 関連データ表示テスト
**説明**: 選択したデータポイントに関連する情報が表示されることを確認する

### 推移グラフ表示テスト
**説明**: 選択したデータの推移グラフが表示されることを確認する
