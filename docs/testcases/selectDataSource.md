# データソース選択のテストケース

## 基本データソース選択テスト

### データソース一覧表示テスト
**説明**: 利用可能なデータソースが一覧表示されることを確認する

### データソース選択テスト
**説明**: データソースを選択できることを確認する

### データソース切り替えテスト
**説明**: 異なるデータソースに切り替えができることを確認する

### データソース詳細表示テスト
**説明**: 選択したデータソースの詳細情報が表示されることを確認する

### データソース検索テスト
**説明**: データソース名で検索できることを確認する

### 権限エラーテスト

### データ形式エラーテスト
