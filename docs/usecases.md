# ユースケース一覧

## 共通機能

### グローバル検索

- **ユースケース名**: globalSearch
- **対象パス**: 
  - `/*`
- **説明**: ヘッダーの検索バーから顧客、リード、商談などをグローバルに検索する
- **入力**: 検索キーワード、検索対象エンティティ（顧客/リード/商談など）
- **出力**: 検索結果一覧（エンティティ名、タイプ、概要情報）、検索結果件数

### 通知確認

- **ユースケース名**: viewNotifications
- **対象パス**: 
  - `/*`
- **説明**: ヘッダーの通知アイコンから新着通知を確認する
- **入力**: ユーザーID、未読フィルタフラグ
- **出力**: 通知一覧（タイトル、内容、日時、既読状態）、未読件数

### ログアウト

- **ユースケース名**: logout
- **対象パス**: 
  - `/*`
- **説明**: ヘッダーのユーザープロフィールメニューからログアウトする
- **入力**: セッションID、ユーザーID
- **出力**: ログアウト成功フラグ、リダイレクトURL

## ダッシュボード

### KPI確認

- **ユースケース名**: viewKPIs
- **対象パス**: 
  - `/`
- **説明**: 売上、商談数、コンバージョン率などの主要KPIを確認する
- **入力**: 期間（開始日、終了日）、対象部門、対象ユーザー
- **出力**: KPI値（売上額、商談数、コンバージョン率、前期比）、グラフデータ

### 今日の活動予定確認

- **ユースケース名**: viewTodayActivities
- **対象パス**: 
  - `/`
- **説明**: 当日の営業活動予定を確認する
- **入力**: ユーザーID、現在日付
- **出力**: 活動予定一覧（活動タイプ、時間、顧客名、場所、ステータス）

### 重要通知確認

- **ユースケース名**: viewImportantNotifications
- **対象パス**: 
  - `/`
- **説明**: 重要な通知やアラートを確認する
- **入力**: ユーザーID、重要度レベル
- **出力**: 重要通知一覧（タイトル、内容、重要度、対応要否、期限）

### 直近の営業活動確認

- **ユースケース名**: viewRecentActivities
- **対象パス**: 
  - `/`
- **説明**: 最近の営業活動履歴を確認する
- **入力**: ユーザーID、表示件数、期間
- **出力**: 活動履歴一覧（活動タイプ、日時、顧客名、結果、次回アクション）

### パイプラインサマリー確認

- **ユースケース名**: viewPipelineSummary
- **対象パス**: 
  - `/`
- **説明**: 商談パイプラインの概要を確認する
- **入力**: ユーザーID、対象期間、対象チーム
- **出力**: ステージ別商談数、ステージ別金額合計、予想成約金額、成約確度

## 顧客管理

### 顧客一覧表示

- **ユースケース名**: listCustomers
- **対象パス**: 
  - `/customers`
- **説明**: すべての顧客情報を一覧で表示する
- **入力**: ページ番号、表示件数、ソート条件、フィルター条件
- **出力**: 顧客一覧（会社名、担当者、業界、電話番号、ステータス）、総件数、ページネーション情報

### 顧客検索

- **ユースケース名**: searchCustomers
- **対象パス**: 
  - `/customers`
- **説明**: 会社名、担当者名、業界などで顧客を検索する
- **入力**: 検索キーワード、検索対象フィールド（会社名/担当者名/業界）
- **出力**: 検索結果一覧（顧客情報）、検索結果件数

### 顧客フィルタリング

- **ユースケース名**: filterCustomers
- **対象パス**: 
  - `/customers`
- **説明**: 業界、規模、地域などで顧客をフィルタリングする
- **入力**: フィルター条件（業界、企業規模、地域、ステータス）
- **出力**: フィルタリングされた顧客一覧、件数

### 顧客ソート

- **ユースケース名**: sortCustomers
- **対象パス**: 
  - `/customers`
- **説明**: 作成日、更新日、売上額などで顧客をソートする
- **入力**: ソート項目（作成日/更新日/売上額）、ソート順序（昇順/降順）
- **出力**: ソートされた顧客一覧

### 顧客一括エクスポート

- **ユースケース名**: exportCustomers
- **対象パス**: 
  - `/customers`
- **説明**: 顧客データをCSVなどの形式でエクスポートする
- **入力**: エクスポート形式（CSV/Excel）、出力対象フィールド、フィルター条件
- **出力**: エクスポートファイル、エクスポート件数

### 新規顧客追加

- **ユースケース名**: createCustomer
- **対象パス**: 
  - `/customers`, `/customers/new`
- **説明**: 新規顧客情報を登録する
- **入力**: 顧客情報（会社名、業界、住所、電話番号、担当者情報）
- **出力**: 登録された顧客ID、登録成功フラグ

### 顧客詳細表示

- **ユースケース名**: viewCustomerDetail
- **対象パス**: 
  - `/customers/:id`
- **説明**: 特定の顧客の詳細情報を表示する
- **入力**: 顧客ID
- **出力**: 顧客詳細情報（基本情報、担当者一覧、商談履歴、コンタクト履歴、関連ドキュメント）

### 顧客基本情報編集

- **ユースケース名**: editCustomerInfo
- **対象パス**: 
  - `/customers/:id`
  - `/customers/:id/edit`
- **説明**: 顧客の基本情報を編集する
- **入力**: 顧客ID、更新情報（会社名、業界、住所、電話番号等）
- **出力**: 更新成功フラグ、更新後の顧客情報

### 担当者情報管理

- **ユースケース名**: manageContacts
- **対象パス**: 
  - `/customers/:id`
- **説明**: 顧客の担当者情報を追加・編集・削除する
- **入力**: 顧客ID、操作タイプ（追加/編集/削除）、担当者情報（名前、役職、メール、電話）
- **出力**: 操作結果フラグ、更新後の担当者一覧

### コンタクト履歴表示

- **ユースケース名**: viewContactHistory
- **対象パス**: 
  - `/customers/:id`
- **説明**: 顧客とのコンタクト履歴を表示する
- **入力**: 顧客ID、期間、フィルター条件（コンタクトタイプ、担当者）
- **出力**: コンタクト履歴一覧（日時、タイプ、内容、担当者、次回アクション）

### コンタクト履歴追加

- **ユースケース名**: addContactRecord
- **対象パス**: 
  - `/customers/:id`
- **説明**: 新しいコンタクト記録を追加する
- **入力**: 顧客ID、コンタクト情報（日時、タイプ、内容、次回アクション）
- **出力**: 登録されたコンタクトID、登録成功フラグ

### 関連商談表示

- **ユースケース名**: viewRelatedDeals
- **対象パス**: 
  - `/customers/:id`
- **説明**: 顧客に関連する商談を表示する
- **入力**: 顧客ID、ステータスフィルター
- **出力**: 商談一覧（商談名、ステージ、金額、予定クローズ日、確度）

### ファイル・ドキュメント管理

- **ユースケース名**: manageDocuments
- **対象パス**: 
  - `/customers/:id`
- **説明**: 顧客に関連するファイルやドキュメントをアップロード・管理する
- **入力**: 顧客ID、操作タイプ（アップロード/削除/ダウンロード）、ファイルデータ
- **出力**: ファイルID、操作結果フラグ、ファイル一覧

### 親会社・子会社関係管理

- **ユースケース名**: manageCompanyRelations
- **対象パス**: 
  - `/customers/:id`
  - `/customers/:id/edit`
- **説明**: 企業の親会社・子会社関係を設定・管理する
- **入力**: 顧客ID、関係タイプ（親会社/子会社）、関連会社ID
- **出力**: 更新成功フラグ、企業関係ツリー

### 顧客削除

- **ユースケース名**: deleteCustomer
- **対象パス**: 
  - `/customers/:id`
- **説明**: 顧客情報を削除する
- **入力**: 顧客ID、削除確認フラグ
- **出力**: 削除成功フラグ、削除されたレコード数
