# 提案書・見積書管理 テストケース

## 概要
商談に関連する提案書や見積書を管理する機能のテストケース

## 基本機能テスト

### TC001: 提案書のアップロード - 正常パターン
**テストケース名**: 商談に提案書ファイルをアップロードする
**説明**: PDFやPowerPointファイルを商談に関連付け
**前提条件**: 
- ユーザーがログインしている
- ドキュメント管理権限を持っている
- 対象の商談が存在する
**テストステップ**:
1. 商談詳細画面を開く
2. 「提案書・見積書」タブを選択
3. 「ファイルアップロード」ボタンをクリック
4. 提案書PDFファイルを選択
5. ドキュメントタイプ「提案書」を選択
6. アップロードを実行
**期待結果**: 
- ファイルが正常にアップロードされる
- ドキュメント一覧に表示される
- アップロード成功メッセージが表示される

### TC002: 見積書の作成・管理 - 正常パターン
**テストケース名**: システム内で見積書を作成・保存
**説明**: 見積書テンプレートを使用した作成機能
**前提条件**: 
- 見積書テンプレートが設定されている
- 商品マスタが整備されている
**テストステップ**:
1. 「新規見積書作成」を選択
2. テンプレートを選択
3. 商品・数量・単価を入力
4. 顧客情報を自動入力確認
5. 見積書を保存
**期待結果**: 
- 見積書が正しく作成される
- 合計金額が自動計算される
- 商談金額と連携される

### TC003: バージョン管理 - 正常パターン
**テストケース名**: 提案書の改訂版を管理
**説明**: 複数バージョンの提案書を履歴管理
**前提条件**: 
- 既存の提案書がアップロード済み
**テストステップ**:
1. 既存提案書の「新バージョン」を選択
2. 改訂版ファイルをアップロード
3. 変更内容をコメントに記録
4. バージョンを保存
**期待結果**: 
- 新バージョンが作成される
- 旧バージョンも保持される
- バージョン履歴が表示される

### TC004: ドキュメントの分類・タグ付け - 正常パターン
**テストケース名**: 提案書・見積書を分類管理
**説明**: カテゴリやタグによる整理機能
**前提条件**: 
- 分類機能が利用可能
**テストステップ**:
1. アップロード済みファイルを選択
2. カテゴリ「技術提案書」を設定
3. タグ「AI」「自動化」を追加
4. 設定を保存
**期待結果**: 
- カテゴリとタグが設定される
- 分類別での検索が可能
- フィルタリングが機能する
