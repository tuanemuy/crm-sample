# お気に入りレポート管理のテストケース

## 基本機能テスト

### お気に入り追加ボタン表示テスト
**説明**: レポート一覧でお気に入り追加ボタンが表示されることを確認する

### お気に入り追加テスト
**説明**: レポートをお気に入りに追加できることを確認する

### お気に入り追加成功メッセージテスト
**説明**: お気に入り追加後に成功メッセージが表示されることを確認する

### お気に入り一覧表示テスト
**説明**: お気に入りに追加したレポートが一覧表示されることを確認する

### お気に入り削除テスト
**説明**: お気に入りからレポートを削除できることを確認する

## お気に入り一覧機能テスト

### お気に入りレポート一覧ページテスト
**説明**: お気に入りレポート専用の一覧ページが表示されることを確認する

### お気に入り件数表示テスト
**説明**: お気に入りの総件数が表示されることを確認する

### お気に入り追加日時表示テスト
**説明**: お気に入りに追加した日時が表示されることを確認する

### お気に入り最終実行日時表示テスト
**説明**: レポートの最終実行日時が表示されることを確認する

### 空のお気に入り表示テスト
**説明**: お気に入りが空の場合に適切なメッセージが表示されることを確認する
