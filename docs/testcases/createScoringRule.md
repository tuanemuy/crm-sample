# 新規スコアリングルール作成 テストケース

## 概要
新しいスコアリングルールを作成する機能のテストケース

## 基本機能テスト

### TC001: 基本的なルール作成 - 正常パターン
**テストケース名**: シンプルな条件でルールを作成する
**説明**: 単一条件のスコアリングルールを新規作成
**前提条件**: 
- ユーザーがログインしている
- ルール作成権限を持っている
**テストステップ**:
1. スコアリング設定画面を開く
2. 「新規ルール作成」ボタンをクリック
3. ルール名「メール開封」を入力
4. 条件「メールを開封した」を設定
5. スコア値「+10」を設定
6. 保存ボタンをクリック
**期待結果**: 
- ルールが正常に作成される
- 作成成功メッセージが表示される
- ルール一覧に新規ルールが表示される

### TC002: 複数条件のルール作成 - 正常パターン
**テストケース名**: AND/OR条件を組み合わせたルール作成
**説明**: 複雑な条件式を持つルールの作成
**前提条件**: 
- ルール作成権限を持っている
**テストステップ**:
1. 新規ルール作成画面を開く
2. ルール名「高エンゲージメント」を入力
3. 条件1「メール開封率 > 50%」AND
4. 条件2「Webサイト訪問回数 > 5」を設定
5. スコア値「+30」を設定
6. 保存を実行
**期待結果**: 
- 複合条件が正しく保存される
- 条件のプレビューが表示される
- ルールが有効化される

### TC003: カテゴリ別ルール作成 - 正常パターン
**テストケース名**: カテゴリを指定してルールを作成
**説明**: 行動、属性、エンゲージメント等のカテゴリ設定
**前提条件**: 
- カテゴリが定義されている
**テストステップ**:
1. 新規ルール作成画面を開く
2. カテゴリで「行動ベース」を選択
3. ルール情報を入力
4. 保存を実行
**期待結果**: 
- カテゴリが正しく設定される
- カテゴリ別一覧に表示される
- フィルタリングが機能する

### TC004: 時間条件付きルール作成 - 正常パターン
**テストケース名**: 期間限定のスコアリングルール作成
**説明**: 特定期間のみ有効なルールの設定
**前提条件**: 
- 日付設定機能が利用可能
**テストステップ**:
1. 新規ルール作成画面を開く
2. 有効期間を設定（開始日・終了日）
3. その他の必要情報を入力
4. 保存を実行
**期待結果**: 
- 期間設定が保存される
- 期間外では自動的に無効化される
- 期間情報が一覧に表示される
