# アプリケーションサービスのテストを修正する

## 背景

- `docs/requirements.md` に要件を定義した
- `docs/backend.md` にバックエンドの実装例を記載した
- `docs/test.md` にテストの実装例を記載した
- `docs/usecases.md` にページ構成とユースケースを定義した
- `docs/testcases/${usecase}.md` に各ユースケースのテストケースを定義した

## タスク

- アプリケーションサービスのテストを、ドキュメントと一致するように修正する

## 条件

## ワークフロー

### 1. 未修正のテストを確認する

```
pnpm task todo test
```

### 2. テストを実装する

- `docs/testcases/${usecase}.md` に各ユースケースのテストケースと一致させる
- `${usecase}.boundary.test.ts` のようにファイルが分割されている場合は、 `${usecase}.test.ts` に統合する
- 実装に合わせず、仕様に合わせたテストを作成する
- ドキュメントが間違っている場合は、ドキュメントを修正する
- やむを得ずリンタールールに違反する場合は、直前の行に `// biome-ignore lint/${rule}: ${reason}` コメントを追加する
- テストは実行しない

### 3. 修正が完了したテストを報告する

```
pnpm task done test ${id}
```
