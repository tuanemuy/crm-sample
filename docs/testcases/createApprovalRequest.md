# 承認申請作成 テストケース

## 概要
商談の承認申請を作成する機能のテストケース

## 基本機能テスト

### TC001: 基本的な承認申請作成 - 正常パターン
**テストケース名**: 商談の承認申請を新規作成する
**説明**: 通常の承認申請フローで申請を作成
**前提条件**: 
- ユーザーがログインしている
- 承認申請権限を持っている
- 対象の商談が存在する
**テストステップ**:
1. 商談詳細画面を開く
2. 「承認申請」ボタンをクリック
3. 承認タイプ「価格承認」を選択
4. 承認者リストから上司を選択
5. 申請理由を入力
6. 申請を提出
**期待結果**: 
- 承認申請が作成される
- 承認者に通知が送信される
- 申請IDが発行される

### TC002: 複数段階承認の申請 - 正常パターン
**テストケース名**: 段階的な承認フローで申請作成
**説明**: 部長→役員の多段階承認申請
**前提条件**: 
- 多段階承認フローが設定されている
**テストステップ**:
1. 高額商談で承認申請を作成
2. 第1段階承認者（部長）を確認
3. 第2段階承認者（役員）を確認
4. 申請理由と根拠を詳細入力
5. 申請を提出
**期待結果**: 
- 多段階承認フローが開始される
- 第1段階承認者から順次処理される
- 各段階の進捗が確認できる

## 異常系テスト

### TC003: 権限不足での申請 - エラーパターン
**テストケース名**: 承認申請権限のないユーザーが申請
**説明**: アクセス権限チェックの確認
**前提条件**: 
- 承認申請権限を持たないユーザーでログイン
**テストステップ**:
1. 商談から承認申請を試みる
**期待結果**: 
- 権限エラーメッセージが表示される
- 申請ボタンが非表示/非活性
- 不正アクセスがログに記録される

### TC004: 必須項目未入力 - エラーパターン
**テストケース名**: 申請理由が未入力での申請
**説明**: 必須項目の入力検証
**前提条件**: 
- 承認申請画面を表示
**テストステップ**:
1. 申請理由を空欄のまま提出
**期待結果**: 
- エラーメッセージが表示される
- 必須項目が強調表示される
- 申請は作成されない

## 通知・連携テスト

### TC005: 承認者への通知 - 通知テスト
**テストケース名**: 申請時の承認者への自動通知
**説明**: メールと社内通知システムでの通知確認
**前提条件**: 
- 通知機能が有効
**テストステップ**:
1. 承認申請を作成・提出
2. 承認者の通知受信を確認
**期待結果**: 
- 承認者にメール通知が送信される
- 社内システムに通知が表示される
- 緊急度に応じて通知方法が変わる

### TC006: 申請者への進捗通知 - 通知テスト
**テストケース名**: 承認進捗の申請者への通知
**説明**: 承認状況の変更時の自動通知
**前提条件**: 
- 承認申請が進行中
**テストステップ**:
1. 承認者が承認/却下を実行
2. 申請者への通知を確認
**期待結果**: 
- 承認結果が申請者に通知される
- 却下理由が含まれる（却下の場合）
- 次のアクションが示される

## 添付・参考資料テスト

### TC007: 参考資料の添付 - 機能テスト
**テストケース名**: 承認申請に参考資料を添付
**説明**: PDFや画像ファイルの添付機能
**前提条件**: 
- ファイル添付機能が利用可能
**テストステップ**:
1. 承認申請作成時に「ファイル添付」を選択
2. 参考資料（PDF）を選択・アップロード
3. ファイル説明を入力
4. 申請を提出
**期待結果**: 
- ファイルが正常に添付される
- 承認者がファイルを参照できる
- ファイル説明が表示される

## 承認フロー制御テスト

### TC008: 緊急承認の申請 - 特別フローテスト
**テストケース名**: 緊急時の特別承認フロー
**説明**: 通常フローをスキップした緊急承認
**前提条件**: 
- 緊急承認権限を持っている
- 緊急承認フローが設定されている
**テストステップ**:
1. 承認タイプで「緊急承認」を選択
2. 緊急理由を詳細に記録
3. 最終承認者を直接指定
4. 申請を提出
**期待結果**: 
- 中間段階がスキップされる
- 最終承認者に直接通知される
- 緊急承認であることが明示される
