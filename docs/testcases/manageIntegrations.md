# 連携管理のテストケース

## 基本機能テスト

### 連携一覧表示テスト
**説明**: 設定済みの連携一覧が表示されることを確認する

### 連携状態表示テスト
**説明**: 各連携のステータス（有効/無効/エラー）が表示されることを確認する

### 利用可能連携一覧テスト
**説明**: 組み込み可能な連携サービスの一覧が表示されることを確認する

### 連携詳細表示テスト
**説明**: 個別の連携の詳細情報が表示されることを確認する

### 連携検索テスト
**説明**: サービス名やカテゴリで連携を検索できることを確認する

## 新規連携設定テスト
