# 商談リスト表示のテストケース

## 基本機能テスト

### リスト表示テスト
**説明**: 商談がリスト形式で表示されることを確認する

### ページネーションテスト
**説明**: 商談リストのページネーションが正しく動作することを確認する

### 商談データ表示テスト
**説明**: 各商談の基本情報が正しく表示されることを確認する

### 空リスト表示テスト
**説明**: 商談が存在しない場合に適切なメッセージが表示されることを確認する

### リスト読み込みテスト
**説明**: 商談リストが正常に読み込まれることを確認する
